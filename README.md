- **Задача предсказания временных рядов** заключается в том, чтобы использовать исторические данные для предсказания будущих значений на основе временной последовательности наблюдений. Временные ряды — это данные, которые записываются в последовательности, упорядоченные по времени, например, цены акций, валютные курсы или погодные условия.
